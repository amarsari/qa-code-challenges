## How to Use This Repository

Each challenge is designed for self-assessment:
1. Open the challenge's `README.md` to review the requirements and system rules without spoilers.
2. Formulate your test scenarios, decision tables, and edge cases.
3. Check `SOLUTION.md` to compare your artifacts against the reference QA analysis, test cases, and Cypress automation.
